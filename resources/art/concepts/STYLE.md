# 角色美术风格 v3 — 大宋军士 · 威而不凶

## 核心原则
**威武而不狰狞**（威而不凶）

| 要 | 不要 |
|----|------|
| 成年男子、下颌清晰、目光坚定 | 娃娃脸、软萌、浅笑讨好 |
| 肃穆、沉稳、有将帅气 | 怒目圆睁、龇牙、魔神脸 |
| 北宋军戎：札甲、战袍、朴素盔 | 纯魔幻尖刺重甲 |
| 红 / 黑蓝阵营分明 | 部落 barbarian 风 |

## 一句话
像「画像里的大宋将官」——立得住、镇得住场，但不是凶神恶煞。
