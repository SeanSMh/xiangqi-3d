# 棋种锁定特征（剪影 ≡ 角色 ≡ 三视图）

> **先锁特征，再出角色，剪影必须从该角色图转出。**  
> 验收以 `silhouettes/pair_character_silhouette_v3.png` 为准。

## 统一风格

- 画风：红方风格化 3D CG；**黑方为同造型 recolor，禁止另起造型**
- 气质：威而不凶
- 占位：待机身体投影 ≤ **0.85 格**；武器优先竖持贴身

## 黑方配色（禁止纯黑涂装）

暗棋盘下纯黑会融进背景。黑方必须：

| 层级 | 规格 |
|------|------|
| 主体甲 | **玄青黑**（深蓝黑，如 `#121c2a`–`#1c2838`），非 `#000` |
| 轮廓可读 | **银色**盔缘、肩甲边、甲片描边、武器刃缘 |
| 环境分离 | **冷蓝轮廓光**（rim light）勾边 |
| 点缀 | 可选暗青扣钉；仕保留玉笏绿作识别 |
| 盔缨 | **禁止红色盔缨**（黑炮等）；用玄黑 / 冷蓝灰 |
| 炮筒 | 箍环可加 **玄青** 色带/标识，与红方铜箍区分 |

### 冷蓝轮廓光

概念图 rim **强度不统一**属正常贴图差异。  
**运行时由引擎/Shader 统一参数**（方向光 + rim intensity/color），不以单张概念图光强为准。

- 造型源：仅 `redesign/red_*_v3.jpg` → `redesign/black_*_v3.jpg`（**扁平目录，无 `black/` 子文件夹**）
- **禁止** `concepts/full_set/black_*`
- 色板：`style_anchor/black_faction_palette.png`
- 锚点：`style_anchor/anchor_black_king.jpg`

## 锁定表 + 验收状态（2026-08 人工评审闭环）

| 棋 | 主识别 | 身高 | 待机 / 占位 | 禁止 | **同源验收** |
|----|--------|------|-------------|------|--------------|
| **帅/将** | **单羽**盔缨 + 佩剑 | 最高 | 无脚底发光台；剪影仅人物 | 双长翎；脚下方框进剪影 | **通过** |
| **仕/士** | **玉笏露出体外轮廓**（顶端须高于肩/盔） | 中 | 笏竖直；可背后高板+胸前笏 | 笏全在身内只靠内描边 | **通过**（v3 高笏露出） |
| **相/象** | 收拢圆盾 + 粗壮 | 中偏宽 | 盾贴身 | 盾大幅外展 | **通过** |
| **相/象 设定** | **有意设计：拟人象军士**（非纯人类） | — | 大宋甲胄 + 象首/象貌 | 与「纯人类军士」混称 | **已写入锁定（有意）** |
| **马** | **半身马**（头颈肩+骑手，无完整四腿） | 特殊 | 压缩/胸像式 | 完整四腿飞奔；剪影另画完整马 | **通过**（剪影已改为半身同源） |
| **车** | 竖长兵 + **足下小轮** | 中 | 枪竖直；轮贴腿缩小 | 剪影有轮立绘无轮 | **通过** |
| **炮** | 扩口火筒 **竖持** | 中 | 待机竖贴身 | 待机横管超格 | **通过** |
| **兵/卒** | 最矮 + **短标枪**（尖约胸高，非通身长矛） | **最矮** | 沉重心；斜持短标枪 | 一人高竖长矛 | **通过**（v3 短标枪；建模按胸高尺度） |

## 攻击态（另出图，不替代待机）

- 炮：端平开火  
- 相：盾外挡  
- 马：可略伸展  

## 剪影规范

1. 从**当前** `redesign/red_*_v3.jpg` 转出，禁止另起炉灶  
2. 纯黑 + 透明/白底；**禁止**脚下光台、UI 框  
3. 识别靠**外轮廓**，不靠体内细节  
4. 运行时只发布 `*_alpha.png` 与 **当前** `silhouettes_sheet.png`（= v3）
