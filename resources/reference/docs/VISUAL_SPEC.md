## 2. 棋盘与场景（Board / Scene）

### 2.1 棋盘

- 标准 **8×8** 格（国际象棋）
- 格面有轻微材质噪点 / 磨损感（非纯色平面）
- 外框：深色金属 + **金色细线**装饰
- 坐标：
  - 底边 **A–H**（金色字母）
  - 两侧 **1–8**（金色数字）
- 参考图：`05_board_scene/board_focus_*.jpg`

### 2.2 环境

- 棋盘置于略抬高的平台
- 周围：断裂柱体、悬浮多面体岩石
- 粒子：缓慢漂浮的小光点
- 无天空盒写实感，偏封闭剧场

### 2.3 相机

- 固定机位，略朝向己方近端（观感上近端棋子更大）
- 对局中 **不旋转**（工具栏有旋转类图标，演示未用）
- 中国象棋复刻建议：同样固定斜俯视；九宫与楚河汉界需完整入画

## 3. 棋子表现（Pieces）

### 3.1 双阵营美术

| 阵营 | 名 | 脚下光圈 | 造型关键词 |
|------|----|----------|------------|
| 白方 | **IVORY** | **蓝色**圆盘 | 中世纪骑士、铠甲、法师长袍、法杖冷光 |
| 黑方 | **OBSIDIAN** | **红色**圆盘 | 部落/羽饰、兽皮、矛、绿发装饰、暖色皮肤 |

### 3.2 头顶徽章（关键可读性）

- 每个角色头顶有 **圆形/盾形徽章**
- 徽章内为 **国际象棋符号剪影**（兵/车/马/象/后/王）
- 边框色与阵营或中性金配合
- **复刻要点**：中国象棋用 **汉字「车马炮相仕帅兵」** 或传统棋子字，字体需远距离可辨

### 3.3 被吃棋子（俘虏列）

- 被吃后不立刻销毁，而是移到棋盘 **左右外侧** 排成纵列
- 仍保留缩小/半透明角色 + 徽章
- 参考：`04_pieces_selection/captured_side/`

## 4. 交互动效（Interaction FX）

### 4.1 选中（Selection）

- **金色圆环** 套在棋子脚下（粗描边、略发光）
- 序列参考：`04_pieces_selection/select_ring/sel_*.jpg`

### 4.2 合法走位提示（Legal moves）

- 可落点：棋盘格上 **白色/浅色光环**（空心圆）
- 可吃点：同样光环，或叠加敌方格强调（演示中以光环为主）
- 序列：`04_pieces_selection/legal_moves/legal_*.jpg`

### 4.3 走子动画（Walk / Move）

- **非瞬移**：棋子沿路径滑动或播放行走循环
- 时长约 **0.4–1.0s**（视距离）
- 到达后站定，光环消失
- 序列：`04_pieces_selection/walk_move/walk_*.jpg`

### 4.4 吃子战斗（Battle systems）— 核心卖点

作者宣传有 **3 套 battle system**。视频中可辨：

| 类型 | 表现 | 参考序列 |
|------|------|----------|
| 白光爆闪 | 落点附近 **大面积白色十字/球状闪光**，短暂过曝 | `03_vfx_battle/seq_white_flash/` |
| 橙火冲击 | **橙黄色爆炸** + 烟雾尘土 | `03_vfx_battle/seq_orange_blast/` |
| 其它吃子 | 冲击波环、火花粒子、角色受击后消失/飞出 | `03_vfx_battle/seq_capture_misc/` |

**时间轴建议（复刻时）**

1. 攻击方走入目标格（0.3–0.6s）
2. VFX 峰值（0.15–0.4s）+ SFX
3. 防守方死亡/退场（0.2–0.5s）
4. 更新 SPOILS、俘虏列（即时）

**中国象棋加分项**

- **炮**：隔子后抛物线弹道 + 落点爆炸（差异化最大）
- **车**：直线冲锋残影
- **马**：跃起弧线再下劈
- **兵过河**：脚下光圈变色/加强

### 4.5 将军（Check）

- 左上角 `TO MOVE` 旁出现红色 **CHECK** 徽章
- 被将军方王/将可能有额外红色脉冲（演示中以 UI 为主）
- 参考：`02_ui_crops/state_check_badge.jpg`、`03_vfx_battle/seq_check_hit/`

### 5.1 SPOILS 面板逻辑

- 标题：`SPOILS`
- 均势：`EVEN`
- 优势：`IVORY +N` 或 `OBSIDIAN +N`（N 为子力差）
- 下方两行小图标：白方被吃 / 黑方被吃（兵车马等剪影）
- 中国象棋可改为：**「战果」** / **「子力」**，用车马炮等汉字或传统棋子图形

### 5.2 工具栏图标（从左到右约）

1. 帮助 / 信息

3. 静音  
4. 视角旋转  
5. 翻转棋盘  
6. 网格/布局  
7. 设置  

复刻时按需精简为：静音、悔棋、新局、翻转、设置。

## 6. 音频

| 文件 | 说明 |
|------|------|
| `06_audio/full_audio.mp3` / `.wav` | 全片音轨（BGM + 音效混合） |
| `06_audio/sfx_clips/sfx_*s.mp3` | 吃子/战斗时刻 1.5s 切片 |

特征：

- 持续低沉/史诗向 BGM
- 吃子时 **高峰值** 冲击/爆炸音
- 走子有较轻的落子或脚步感（混在 BGM 里）

复刻建议：BGM 与 SFX 分层；中国风可换古筝/鼓点，但 **吃子冲击感** 建议保留电子/合成器撞击以贴近原版爽感。
