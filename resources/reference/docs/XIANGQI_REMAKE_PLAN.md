# 中国象棋 3D 对战 — 复刻开发计划

基于原版 3D Chess Battle 的产品结构，做 **规则正确 + 演出对标** 的中国象棋。

---

## 目标定义

**一句话**：固定斜俯视 3D 场景里，用红黑人偶棋子下完整中国象棋；走子有动画，吃子有战斗特效，UI 有行棋方 / 将军 / 战果。

**成功标准（MVP）**

1. 红黑轮流，全部棋规合法（含蹩马腿、塞象眼、炮架、将帅对面、绝杀）  
2. 点选 → 合法点高亮 → 走子动画 → 吃子 VFX  
3. 将军提示、简单双人同屏  
4. 视觉气质对齐参考包（暗场 + 光圈 + 徽章）

---

## 模块拆分

```
┌─────────────────────────────────────────┐
│  Presentation（Three.js / Unity）        │
│  棋盘网格 · 角色 · VFX · 相机 · 音效      │
├─────────────────────────────────────────┤
│  Input / UI                              │
│  点选 · HUD · 战果 · 菜单                 │
├─────────────────────────────────────────┤
│  XiangqiEngine（纯逻辑，无渲染）          │
│  局面 · 着法生成 · 将军 · 胜负            │
└─────────────────────────────────────────┘
```

规则与渲染 **严禁耦合**，否则特效一改就坏棋。

## 棋盘规格（中国象棋）

| 项 | 值 |
|----|-----|
| 结构 | 9 条竖线 × 10 条横线，**棋子在交叉点** |
| 河 | 第 5–6 横线之间「楚河 / 汉界」 |
| 九宫 | 双方底线中央 3×3 斜线宫 |
| 坐标建议 | 竖线 1–9（或九八七…中式），横线 1–10 |
| 世界尺寸 | 建议格距 1.0 单位；河带宽 0.5–1.0 视觉缝 |

**与原版差异**

- 原版是 **格心** 站子；象棋是 **交点** 站子  
- 需画河界文字与九宫 X 线

## 动效实现要点

### 选中 / 合法点

- 选中：金色 torus 或贴地 ring，轻微呼吸缩放  
- 合法点：半透明白环；可吃：红环或脉冲  

### 走子

```
duration = clamp(distance * 0.12, 0.35, 0.9)  // 秒
easing = easeInOutCubic
// 炮吃子：可先「后坐」再弹道
```

### 吃子状态机

```
IDLE → WINDUP → STRIKE_VFX → VICTIM_EXIT → SETTLE → IDLE
```

VFX 资源可从参考序列描摹节奏：

- 白闪：`03_vfx_battle/seq_white_flash/`（约 2.5s@30fps）  
- 橙爆：`03_vfx_battle/seq_orange_blast/`  
- 多段参考：`seq_capture_misc/`  

MVP 可用：

1. 一张广告牌光晕 sprite 放大淡出  
2. 10–20 个粒子 outward burst  
3. 镜头微震 0.1s（可选）  

### 炮（差异化）

```
炮架存在 → 炮弹 mesh 沿抛物线飞到目标 → 落点 VFX → 目标退场
```

## 开发阶段

### Phase 0 — 规则引擎（1–2 天）

- [ ] 局面表示（10×9 或 bitboard）  
- [ ] 各子着法生成  
- [ ] 将军 / 将被吃检测 / 将帅照面  
- [ ] 合法着过滤（被将军时只能应将）  
- [ ] 单元测试：开局、典型杀法、闷宫、困毙  

### Phase 1 — 简 3D 可玩（2–3 天）

- [ ] 点阵棋盘 + 河 + 九宫线  
- [ ] 占位棋子（圆柱/棋子模型 + 字）  
- [ ] 点选、合法点、走子补间  
- [ ] 红黑轮流 + 将军 UI  

### Phase 2 — 对标原版观感（3–5 天）

- [ ] 阵营光圈、徽章  
- [ ] 吃子 VFX ×2 套 + SFX  
- [ ] 战果面板 + 俘虏列  
- [ ] 暗色场景与灯光  
- [ ] 炮弹道  

### Phase 3 — 可传播（可选）

- [ ] 低模角色 + 走/攻动画  
- [ ] 简单电脑对手（αβ + 子力）
- [ ] 音效包 / 中国风 BGM  
- [ ] Web 分享链接
